# Saved results / 保存結果

Exact JSON expressions and CSV data are generated by `script/paper06.py recompute`. Rendering reads saved data only; recomputation writes a new directory. `manifest.json` records hashes, the environment and checks.

| File | Contents / 内容 |
| --- | --- |
| classification.json | Four fixed geometries / 四幾何の曲率 |
| geometry.json | Class-A curvature and endpoint identities / 曲率・端点 |
| reduction.json | Action, variations and constraints / 作用・拘束 |
| regimes.json | Static and dynamic restrictions / 制限 |
| field_equations.json | Full equation residuals / 全方程式残差 |
| orbits.csv, pulse.csv | Reduced orbit and off-shell pulse curves / 図データ |
| shape_variation.json | General first/second shape action / shape作用 |
| torus_deformations.json | Pure scale, coordinates, endpoints, cone and exact family / torus |
| curvature_invariants.json | Quadratic/cubic contractions and Ricci inverse map / 不変量 |
| short_time_evolution.json | Diagonal ODE and exact initial jets / 短時間係数 |
| short_time_checks.csv | 12 prescribed numerical points / 数値対照 |
| global_frames.json | Torus frame, connection and period data / 大域frame |
| canonical_representatives.json | Generator, constraints and canonical map / 正準対応 |

Expressions use SymPy notation. Each `identities` list names checks actually performed. Numerical fields are finite-point comparisons, not interval bounds. `figure_slice` specifies two orthonormal shear directions and a plotting grid, not a physical degree count.

The argument is contained in the main text and Appendices A–D. See [English](../../script/README.md) / [日本語](../../script/README_ja.md) and [conventions](../../script/CONVENTIONS.md).
