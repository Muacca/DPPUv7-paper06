\section{Supplementary material}

The accompanying \texttt{script}, \texttt{data} and \texttt{LaTeX} folders contain curvature components, action, constraints and endpoints; shape variations and the exact torus family; quadratic and cubic invariants and the Ricci inverse problem; short-time coefficients and 12 numerical comparisons; global frames; canonical correspondence; and the English source. Bilingual instructions distinguish saved-data-only \texttt{render} from explicit \texttt{recompute} into a new output directory. The definitions and proofs are in the main text and Appendices A--D; running the code is not a prerequisite for the argument. The supplementary comparison guide records convention conversions.
